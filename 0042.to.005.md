# Roadmap: v0.0.4.2 → v0.0.5

## v0.0.4.2 - Bug Fixes & UX Improvements

### Critical Fixes
- **Fix CLI display bug**: When clicking non-arrow buttons, corrupted strings appear in the output space (^[[A^[[B), blocking further functionality. Resolve terminal input handling.
- **Fix Config File Editor messaging**: Remove misleading "No EDITOR/VISUAL environment variable is set" error message. The file can already be accessed via Settings → "View Config File Location" → edit in Finder.

### Settings Enhancement
- **"View Config File Location" improvement**: 
  - macOS: Open the config folder in Finder
  - Windows: Display the file location path in the CLI
  - This gives users direct access to the config file for editing

## v0.0.4.3 - Theme System

### Theme Additions
Add the following color themes to the application:
- **Red** - Red color scheme
- **Orange** - Orange color scheme
- **Green** - Green color scheme
- **Cyan** - Cyan color scheme
- **Dark Blue** - Replace current blue with a darker variant
- **Pink** - Replace current pink with refined variant
- **Black** - High contrast: black text on black background (use #000000 for both)

## v0.0.5 - Major Feature Expansion

### New Section: Graphing Tool
Create a dedicated **Graphing** section under the Main menu as a top-tier feature alongside Chem and AI.

**Features:**
- Allow users to create and visualize functions like f(x) = x²
- Build the most comprehensive graphing tool available
- Full plotting capabilities with interactive functionality
- Nested menu structure for organization

### Additional Expansions
- Expand platform capabilities beyond Chem and AI offerings
- Prepare architecture for future feature additions
